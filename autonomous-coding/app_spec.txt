# TimeLine 2026 - 年度倒计时可视化平台

## 项目概述

一个简洁、现代的 Web 应用，帮助用户追踪 2026 年度的重要时间节点：中国法定节假日和各类职业资格考试。采用卡片式时间线布局，通过直观的倒计时可视化，帮助备考人群和职场人士规划年度时间。

**核心价值**：
- 一目了然的时间进度感知
- 减少对重要日期的焦虑感
- 温暖鼓励的使用体验

**目标用户**：
- 备考人群（教师资格、CPA、司法考试、建筑师等）
- 职场人士（规划假期、工作节奏）
- 学生群体（考试日程管理）

### Feature 2: 事件卡片组件 (EventCard)

**描述**：可复用的事件卡片组件，展示单个节假日或考试信息。

**Props 定义**：
```typescript
interface EventCardProps {
  event: Event;
  variant: 'default' | 'compact' | 'urgent';
  showFavorite?: boolean;
  onClick?: () => void;
}

interface Event {
  id: string;
  name: string;
  type: 'holiday' | 'exam';
  category?: string;        // 考试类别（财务、建筑、教育、公务员等）
  subCategory?: string;     // 子类别（国考、省考、市考等）
  date: string;             // ISO 格式日期
  endDate?: string;         // 多日事件结束日期
  duration?: number;        // 放假天数
  quarter: 'Q1' | 'Q2' | 'Q3' | 'Q4';
  quote: string;            // 励志文案
  icon?: string;            // emoji 图标
  officialUrl?: string;     // 官方链接
  description?: string;     // 详细描述
  provinces?: string[];     // 适用省份（省考）
  cities?: string[];        // 适用城市（市考）
}
```

**验收标准**：
- [ ] 卡片显示事件名称（最多2行，超出省略）
- [ ] 卡片显示大号倒计时数字（剩余天数）
- [ ] 卡片显示辅助时间信息（剩余周数+天数）
- [ ] 卡片显示具体日期（格式：X月X日）
- [ ] 节假日显示放假天数标签
- [ ] 卡片右上角显示季度标签（Q1-Q4）
- [ ] 已结束事件显示灰色样式 + "已结束"标签
- [ ] 7天内事件显示红色边框 + 火焰图标
- [ ] 点击卡片展开详情弹窗
- [ ] 鼠标悬停有微妙上浮效果（translateY: -4px）

**UI 规格**：

### Feature 12: 自定义事件倒计时增强

**描述**：增强自定义事件功能，支持为任意事件创建倒计时，包括个人纪念日、生日、目标日期等。

**验收标准**：
- [ ] 自定义事件显示在主时间线中，与其他事件样式一致
- [ ] 自定义事件卡片左上角显示"自定义"标签
- [ ] 支持设置事件类型：生日、纪念日、目标、其他
- [ ] 支持设置重复周期：不重复、每年重复（生日/纪念日）
- [ ] 支持设置提前提醒：1天前、3天前、1周前、不提醒
- [ ] 自定义事件支持编辑和删除
- [ ] 重复事件自动计算下一次日期（如：生日每年自动更新）
- [ ] 事件详情弹窗中显示编辑/删除按钮

## 工具函数

### useCountdown.ts

```typescript
import { useState, useEffect, useMemo } from 'react';

interface CountdownResult {
  days: number;
  weeks: number;
  remainingDays: number; // 周数后的剩余天数
  isPast: boolean;
  formatted: string; // "5 周 2 天"
}

export function useCountdown(targetDate: string): CountdownResult {
  const [, setTick] = useState(0);

  useEffect(() => {
    // 每分钟更新一次
    const interval = setInterval(() => setTick(t => t + 1), 60000);
    return () => clearInterval(interval);
  }, []);

  return useMemo(() => {
    const now = new Date();
    const target = new Date(targetDate);
    const diffMs = target.getTime() - now.getTime();
    const diffDays = Math.ceil(diffMs / (1000 * 60 * 60 * 24));

    const isPast = diffDays < 0;
    const absDays = Math.abs(diffDays);
    const weeks = Math.floor(absDays / 7);
    const remainingDays = absDays % 7;

    return {
      days: diffDays,
      weeks,
      remainingDays,
      isPast,
      formatted: diffDays >= 0
        ? `${weeks} 周 ${remainingDays} 天`
        : `已过去 ${weeks} 周 ${remainingDays} 天`
    };
  }, [targetDate]);
}
```

## 边缘情况处理

1. **已结束事件**：显示在折叠的"已结束"区域，样式变灰，倒计时为 0
2. **当天事件**：倒计时显示 "0 天"，标签显示"今天"
3. **跨年事件**：年份显示完整日期（2026-01-01）
4. **多日事件**：显示日期范围（X月X日 - X月X日）
5. **空搜索结果**：显示友好提示"没有找到相关事件"
6. **无收藏**：收藏筛选显示"还没有收藏任何事件"
7. **LocalStorage 不可用**：静默降级，不保存用户偏好
8. **时区处理**：统一使用中国时区 (Asia/Shanghai)

- `feat`: 新功能

- `events`: 事件相关组件

```
feat(events): 添加事件卡片组件

- 实现 EventCard 基础结构
```

```yaml
          if [ $(cat coverage/coverage-summary.json | jq '.total.lines.pct') -lt 80 ]; then
            echo "Coverage below 80%"
            exit 1
          fi

      - name: Build
        run: npm run build
```
