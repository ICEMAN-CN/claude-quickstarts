# 小红书图文自动生成器

## 项目概述

一个 Web 应用，帮助用户自动生成小红书风格的图文内容。用户输入主题或关键词，系统自动生成吸引人的标题、正文、标签，并提供配图建议。

## 技术栈

- 前端：React + Vite + Tailwind CSS
- 后端：Node.js + Express
- 数据库：SQLite
- AI 接口：支持 OpenAI/Claude API（可配置）

## 功能需求

### 1. 用户输入模块
- 文本输入框：用户输入主题/关键词
- 风格选择：种草/教程/测评/分享/日常
- 语气选择：活泼/文艺/专业/幽默
- 目标人群选择：学生/白领/宝妈/健身/美妆

### 2. 内容生成模块
- 标题生成：生成 5 个爆款标题供选择
- 正文生成：自动生成带 emoji 的小红书风格正文
- 标签生成：生成 10-15 个相关话题标签
- 字数统计：显示正文字数（建议 300-800 字）

### 3. 内容编辑模块
- 标题编辑：用户可修改选中的标题
- 正文编辑：富文本编辑器
- emoji 快捷插入：常用 emoji 面板
- 一键复制：复制生成的内容

### 4. 配图建议模块
- 图片数量建议：推荐 3-9 张图
- 构图建议：为每张图提供拍摄/选图建议
- 图片尺寸提示：3:4 竖版最佳
- 封面文字建议：首图文字排版建议

### 5. 历史记录模块
- 保存生成的草稿
- 查看历史生成记录
- 搜索和筛选历史
- 删除历史记录

### 6. 模板库模块
- 预设热门模板：美妆/穿搭/美食/旅行/学习
- 自定义模板保存
- 模板分类管理

### 7. 设置模块
- API Key 配置
- 默认风格设置
- 默认语气设置
- 数据导出功能

## UI 设计要求

- 配色：小红书品牌红 (#FF2442) + 白色 + 浅灰
- 字体：系统默认字体，标题加粗
- 布局：左侧输入区，右侧预览区
- 响应式：支持移动端访问

## 数据模型

### Draft（草稿）
- id: 主键
- title: 标题
- content: 正文
- tags: 标签（JSON 数组）
- style: 风格
- tone: 语气
- created_at: 创建时间
- updated_at: 更新时间

### Template（模板）
- id: 主键
- name: 模板名称
- category: 分类
- prompt_template: 提示词模板
- created_at: 创建时间

### Settings（设置）
- id: 主键
- key: 设置键
- value: 设置值

## API 接口

### 内容生成
- POST /api/generate/title - 生成标题
- POST /api/generate/content - 生成正文
- POST /api/generate/tags - 生成标签
- POST /api/generate/all - 一键生成全部

### 草稿管理
- GET /api/drafts - 获取草稿列表
- POST /api/drafts - 保存草稿
- PUT /api/drafts/:id - 更新草稿
- DELETE /api/drafts/:id - 删除草稿

### 模板管理
- GET /api/templates - 获取模板列表
- POST /api/templates - 创建模板
- PUT /api/templates/:id - 更新模板
- DELETE /api/templates/:id - 删除模板

### 设置
- GET /api/settings - 获取设置
- PUT /api/settings - 更新设置

## 质量要求

- 所有 API 需要有错误处理
- 前端需要有加载状态提示
- 敏感信息（API Key）不能暴露到前端
- 代码需要有基本注释

## 部署要求

- 开发环境：npm run dev 同时启动前后端
- 生产构建：npm run build
- 端口：前端 3000，后端 3001
